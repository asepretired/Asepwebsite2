Reboot Standard
adb reboot

Memuat ulang sistem operasi Android target secara bersih untuk memperbarui cache sistem atau setelah update konfigurasi.

Reboot Recovery
adb reboot recovery

Mengarahkan perangkat langsung ke partisi Recovery Mode (Stock / TWRP / OrangeFox) untuk wipe data, flashing ZIP, atau backup.

Reboot Bootloader / Fastboot
adb reboot bootloader

Mematikan OS dan masuk ke antarmuka low-level Fastboot untuk unlocking bootloader atau flashing partisi boot/vendor.

Mematikan Daya (Power Off)
reboot -p

Mematikan daya perangkat secara aman (graceful shutdown) tanpa menekan tombol power fisik perangkat.

Android Interactive Shell
adb shell

Menjalankan perintah terminal sistem internal Android berhak akses shell (Toybox/BusyBox) secara real-time.

Install APK Langsung
adb install -r file.apk

Mengirim dan memasang package APK dari HP A/komputer langsung ke HP target tanpa konfirmasi UI instalasi package installer.

Lifecycle & Manajemen Aplikasi
pm / am

Kendalikan eksekusi package target: buka activity utama, hentikan paksa proses (force stop), atau cabut izin.

Pembersihan Data & Cache
pm clear

Hapus seluruh local database, SharedPreferences, serta cache aplikasi target tanpa perlu menghapus aplikasi tersebut.

Freeze / Disable Package
pm disable-user

Bekukan bloatware atau nonaktifkan aplikasi sistem tanpa root dan pulihkan statusnya kapan saja.

Daftar & Informasi Detail Package
pm list / dumpsys

Melihat seluruh daftar package aplikasi pihak ketiga maupun bawaan OEM beserta informasi signature dan permission.

Push File (Kirim ke Target)
adb push

Mengirim dokumen, script, atau gambar dari perangkat lokal A ke direktori storage HP target (/sdcard/Download).

Pull File (Tarik ke Lokal)
adb pull

Mengunduh file log, database SQLite, atau foto dari memori HP target ke perangkat lokal yang membuka website ini.

Struktur Direktori & Operasi File
ls / rm / cp / mkdir

Eksplorasi folder filesystem Android, buat folder baru, pindahkan data, atau bersihkan direktori yang memiliki izin akses.

Capture & Screen Record
screencap / screenrecord

Ambil tangkapan layar instan tanpa watermark atau rekam interaksi layar hingga 3 menit dalam resolusi native target.

Simulasi Input Teks & Touch
input tap / text

Kirimkan pengetikan teks otomatis atau sentuhan koordinat (X, Y) secara presisi ke antarmuka HP target.

Simulasi Tombol Hardware
input keyevent

Kirim event tombol fisik seperti tombol Home, Back, Power, Volume, dan App Switcher.

Parameter Display & Resolusi
wm size / wm density

Ubah resolusi virtual atau DPI display secara dinamis untuk menguji responsivitas antarmuka aplikasi.

Logcat Reader
adb logcat -v time

Stream logs dari runtime Android untuk melihat pesan debug, log warning, hingga exception crash.

Resource & Hardware Telemetry
dumpsys / top

Monitor penggunaan CPU per proses, status baterai (level, voltase, temperatur), dan alokasi RAM.

Informasi Sistem Menyeluruh
getprop / uname

Mengambil parameter kernel Linux, versi Android OS SDK, security patch level, dan status SELinux perangkat.

Wireless ADB (Wi-Fi TCP/IP)
adb tcpip 5555

Aktifkan port debugging 5555 pada target untuk mencabut kabel dan melanjutkan kontrol penuh secara nirkabel melalui jaringan lokal Wi-Fi.

Port Forwarding & Reverse
adb forward / reverse

Petakan port server lokal (misal localhost:3000) ke port target atau sebaliknya untuk pengetesan backend lokal di HP.

Deep Link & Intent Testing
am start -a -d

Uji skema URL Custom URI Scheme dan App Links tanpa harus membangun ulang kode di Android Studio.

Jalankan Activity / Service Eksplisit
am start-service

Trigger service latar belakang atau buka screen activity internal secara langsung dengan membawa extra parameter string/boolean.

Android Full Bugreport
adb bugreport

Menghasilkan arsip diagnostik komprehensif (.zip) berisi dumpstate, memory leak trace, radio log, and ANR traces untuk analisa mendalam.
