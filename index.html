Reboot Standard
adb reboot

Memuat ulang sistem operasi Android target secara bersih untuk refresh system cache atau reset temporary flag.

Reboot Recovery
adb reboot recovery

Mengarahkan perangkat langsung ke partisi Recovery (Stock, TWRP, OrangeFox) untuk wipe cache / flashing ROM.

Bootloader / Fastboot
adb reboot bootloader

Masuk ke interface Fastboot/Bootloader low-level untuk flash partisi boot/vendor atau OEM unlock.

Matikan Daya (Power Off)
adb shell reboot -p

Mematikan sistem operasi secara graceful shutdown tanpa menyentuh tombol hardware fisik.

Android Interactive Shell
adb shell <cmd>

Jalankan instruksi Toybox/Busybox internal Android OS langsung dan terima feedback teks di terminal.

Pasang APK (Direct Sideload)
adb install -r

Pilih file package APK dari storage lokal untuk dikirim langsung ke sistem target tanpa konfirmasi UI.

Kontrol Lifecycle Package
pm / am

Target Package Name yang sedang dianalisa atau diubah statusnya secara langsung.

Pembersihan Cache & Data
pm clear

Mengosongkan SQLite database, file session token, dan cache aplikasi target secara instan.

Freeze / Disable Bloatware
pm disable-user

Nonaktifkan bloatware OEM tanpa root dan pulihkan statusnya (enable) kapan pun.

Daftar Paket Terpasang
pm list packages

Mencari dan menampilkan seluruh package aplikasi pihak ketiga atau package sistem internal.

Push File ke Target
adb push

Mengirim file lokal dari browser ke folder penyimpanan internal perangkat Android target (/sdcard/Download/).

Pull File dari Target
adb pull

Download log, database, atau screenshot yang ada di storage internal target ke browser Anda.

Eksplorasi Filesystem
ls / mkdir / rm

Navigasi dan manipulasi struktur folder pada partisi internal Android.

Screen Capture
screencap

Mengambil gambar tampilan layar secara instan dalam format file PNG murni tanpa watermark.

Injeksi Teks & Ketikan
input text

Kirimkan pengetikan teks otomatis ke input textfield yang sedang aktif di layar target.

Simulasi Tombol Navigasi
input keyevent

Kirim perintah tombol fisik untuk navigasi cepat.

Display Metrics & DPI
wm size / density

Periksa atau ganti resolusi dan densitas layar secara real-time.

Android Logcat Engine
adb logcat

Baca alur log internal OS, filter pesan peringatan (warn), error, hingga application crash traces.

Status Daya & Hardware
dumpsys battery

Diagnostik kesehatan sel baterai, suhu sensor termal, voltase, dan alokasi konsumsi daya.

Audit Parameter Sistem (Properties)
getprop / uname

Informasi detail arsitektur CPU, versi Android kernel Linux, dan status proteksi SELinux.

Wireless ADB (Wi-Fi TCP/IP)
adb tcpip 5555

Aktifkan daemon ADB di port TCP 5555 sehingga kabel USB dapat dicabut dan dilanjutkan via Wi-Fi.

Port Forwarding & Reverse
adb reverse / forward

Jembatani port localhost komputer/host ke ponsel untuk pengetesan backend lokal langsung di HP.

Intent & Deep Link Testing
am start -a -d

Lakukan routing trigger Custom URL Scheme atau Android App Link tanpa membuka browser manual di HP.

Bugreport Generator
adb bugreport

Dump diagnostic log komprehensif berisi dumpstate memori, crash ANR, dan status sistem radio.
